| cofacts-ai                   | CPU p50 極低(~0.015,幾乎閒置)           | p99 07-19 出現單日尖峰(0.469,為期間最高)          | 07-19 有一次性負載尖峰,之後回穩                   |

**⚠️ 重點發現**:`site-tw`、`site-staging-tw/ja/en` 這幾個服務的 CPU 與 Memory p99 在多個日期都精準落在同一個數值(~1.0118),這通常代表指標已達到 Cloud Run 容器的資源配額上限(而非真實用量),意味著實際負載可能被截斷/節流。建議之後檢查這幾個服務的 CPU/Memory 配置上限是否需要調高,尤其 `site-tw` 是主要對外服務。
